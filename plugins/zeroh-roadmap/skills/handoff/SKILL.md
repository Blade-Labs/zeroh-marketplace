# Handoff

Update typed phase/arc progress with completed work, observed checks, remaining findings and deferred outcomes. Preserve the immutable approved-intent reference and actual owner ratifications. Record the branch/worktree and next concrete action where the next session can find them; link canonical records rather than copying the transcript.

Inspect outstanding native tool runs before handing off. Say whether they exited, failed or remain unobserved. Do not infer completion from a stale log. Keep an ownership claim held until explicit owner-matching release or checked handoff; a new session must not silently take over another owner's claim.

Provide one short resume instruction naming the arc/phase and checkout. A separate handoff document is needed only for useful context the typed record cannot hold. No mandatory journal, digest, report fields or full session dump.
