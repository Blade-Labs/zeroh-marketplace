# External dependencies and assets

Read and follow the consumer's actual licensing and distribution policy before introducing packages, fonts, icons, images, snippets or models. Do not assume that a policy from another project applies universally.

Check the selected upstream license and relevant shipped attribution rather than trusting a README badge. Record the dependency choice where it has lasting value. If terms are unknown, incompatible with the consumer policy or require an unresolved owner decision, resolve that specific issue before adoption; a model's confidence is not consent.

Use existing dependency/license checks when available. Do not add a mandatory new scanner, report template or architect ceremony to every ordinary dependency update.
