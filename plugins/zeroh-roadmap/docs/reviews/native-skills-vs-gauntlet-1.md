# Native skills compared with Gauntlet 1.0

Reviewed 2026-09-09 against the actual release `zeroh-roadmap/v0.30.0`, peeled commit `1518f5817914eb671f824bb2b24f6d817c4f2792`, immediately after winning installs `478aa67`. The candidate comparison started at `51091a5`; this review accompanies the targeted instruction repairs. Sources: committed skill/agent bodies, relevant removed references and the [public Gauntlet report](GAUNTLET-2026-08.md). No sealed benchmarks were accessed or additional native trials run.

## Finding

The native supervisor loop is coherent, but the first reduction removed some useful judgment along with the engine. Restore those short instructions while keeping rolling planning, native ownership, independent acceptance and proportional review. Three independent source-review assignments covered planning/design, execution/acceptance, and supporting review/testing; the supervising review covered integration and the developer card. An independent follow-up found no blocking contradiction in the repairs.

## Intentional removals

Do not restore full upfront task planning, mandatory per-task commits/prose, detached workflow drivers, model registry, fixed panels, gate report grammars, scoring, or automatic quality-pass cleanup. `eval-arc` and its judge were deliberately retired with scoring. Gauntlet 1.0 had already retired the separate `code-review` skill; the reviewer card remains. There is no researcher card in either compared inventory.

## Verification and limits

Check changed Markdown links and shipped command references, manifest consistency and the current source inventory. The existing native observations covered one phase and rolling continuation on each host; they predate these instruction repairs and are not new comparative evidence. No runtime sources were added by this review.

Gauntlet 1.0 found losing rewrites that looked good in inspection. Accordingly, this review supports structural coherence and identifies repaired instruction omissions; it does **not** prove behavioral parity or superiority to the Gauntlet winner. Future observed use should target these repaired failure modes rather than replay a large campaign by default.
