# Product requirements

## Product
Create a small command-line greeter that takes a name and prints a greeting.

## Audience
A beginner learning JavaScript.

## Platforms
Local command line with Node.js.

## Constraints
Keep the foundation small, runnable and understandable.

## Non-goals
UI, cloud hosting, CI and release workflows.

## Success signals
The documented command in [README](../README.md) runs the prototype; one meaningful automated test passes.

## Brand
No UI or Blade branding.

## Decisions
The product packet supplies the scope. Stack rationale is in [the stack record](adr/0001-tech-stack.md). Consumer execution requires explicit approval. The actual approval response and approved scope must be recorded here after it arrives; none has been received during proposal preparation.
