# Archetype manifest contract

## Generator
One fenced block containing a literal generator command.

## Post-steps
Exact approved edits after generation.

## File tree
One fenced, non-empty two-level tree.

## Conventions delta
Only archetype-specific additions to the shared conventions.

## testConventions
At least two literal commands or patterns.

## designHomes
The architecture and UX pointers consumed by the roadmap.

## Verify
Exactly one fenced, single-line exit-code command. Keep observations and dates
only in `VERIFY-RECORD-2026-09.md`.
