# Choose a recipe

Read only recipes relevant to the selected requirements. These are documentation recipes, not prebuilt applications or validated platform support. Verify changing generator/tool instructions from official sources when used, then observe the actual run and meaningful test on each required target. An untested platform stays unverified.

| Need | Recipe |
| --- | --- |
| Browser or server-backed application | [Web](web.md) |
| Android-native application | [Android](android.md) |
| React Native mobile application | [Expo](expo.md) |
| Dart cross-platform application | [Flutter](flutter.md) |
| Desktop application | [Desktop](desktop.md) |
| Multiple required surfaces | [Combined](combined.md) |
| Several projects with justified graph tooling | [Nx workspace](nx-monorepo.md) |
| Package or command-line tool | [Library / CLI](library-cli.md) |

Examples are not defaults. Preserve the approved stack; adapt its actual generator and output. `designHomes` means canonical PRD/architecture/test guidance paths, which may be README sections, not a required configuration shape.
