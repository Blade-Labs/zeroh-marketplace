# Link canonical homes

Find the existing PRD, architecture, standards and test/run-command homes before creating any. Add links from the project's README or agent guidance; avoid competing copies. Small projects may keep these sections in one document.

When Roadmap is used, link relevant homes in its typed arc references using the consumer's actual schema. Read legacy `designHomes` and `testConventions` paths as guidance; these mean canonical document/command locations, not a required JSON configuration contract. Greenfield does not require Roadmap, write gate slots, or run a Roadmap configuration check.

Existing consumer scripts, workflows and configuration belong to that project. A plugin update does not authorize deletion, migration or regeneration of them.
