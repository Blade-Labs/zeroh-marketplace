# Choose the useful guidance

Inspect the request and existing project guidance, manifests and source. Reuse known product and stack decisions.

- New project or first prototype: use `greenfield-init`.
- Existing implementation, audit or missing practices: use `brownfield-audit`.
- A consequential unresolved stack choice: use `stack-decision`.
- Asked for guidance later: read the relevant recipe without restarting setup.

A README, Git repository or empty package manifest alone does not establish a working application. Inspect actual implementation before routing. Preserve existing files in either path.

Greenfield works without Roadmap. If Roadmap is installed, it can consult these skills at initialization or before planning; declining foundation suggestions never blocks Roadmap use. No capability negotiation, configuration gate or special runtime is needed.
