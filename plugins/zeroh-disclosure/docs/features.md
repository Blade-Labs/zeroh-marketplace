# Features

Every user-visible feature of ZeroH Disclosure 1.0.0, with its status on each platform the
plugin targets. Use it to track parity as ZeroH comes to Codex and OpenCode. The list is grouped by
area; a feature that works the same way on every host, or a subcommand of a larger feature, is part
of that feature's row rather than a row of its own.

[features.json](features.json) holds the same list for tools: each feature's ID, area and
description, and per platform `{status, note, sources}`, where `sources` names the documentation,
source lines or live runs a status rests on. It is the source; the tables below are generated from it
(`node scripts/features.mjs --write`), a test keeps the two in sync, and every feature names the
code or test that implements it. The release pipeline refuses a release whose list is out of date,
and each CHANGELOG section lists the feature IDs it adds or changes on a `Features:` line.

**Statuses.** `shipped`: in this release. For a platform ZeroH does not ship on yet: `planned`
means the host allows it (the note says how); `partial` means the host allows only part of it (the
note says what is missing); `not possible` gives the reason; `unknown` means not researched or not
verified yet. Questions that need a live run are in [parity-open-questions.md](parity-open-questions.md).

**Versions.** The statuses come from research on 2026-09-28: the host documentation and source, and
live runs where the note says so.

- **Codex**: Codex CLI 0.158.0. Its documentation moved from developers.openai.com/codex to
  [learn.chatgpt.com/docs](https://learn.chatgpt.com/docs).
- **OpenCode 1.x**: `opencode-ai` 1.18.33, still the default install.
- **OpenCode 2**: `@opencode/cli` 2.0.18, a separate package with a new plugin API
  (`Plugin.define({id, setup})`); v1 plugins don't run on it, so it has its own column.
- **Next platforms**: GitHub Copilot, Cursor and Gemini CLI are the likeliest next hosts. A
  documentation scan covered only the core features, so they have their own table below; every
  other feature is `unknown` for them in features.json.
