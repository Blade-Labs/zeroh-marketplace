# specify

Write the smallest useful problem statement before planning.

Produce:

- user goal and business reason
- named owner or accountable surface
- evidence inputs
- non-goals
- initial acceptance signals
- candidate Zod shapes or parse boundaries

Do not pick implementation files yet unless they are part of the evidence. Hand off to `clarify` if material ambiguity remains, otherwise hand off to `execution-spec`.
